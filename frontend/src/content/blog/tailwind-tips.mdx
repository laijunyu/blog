## 为什么选择 Tailwind CSS

Tailwind CSS 是一个实用优先的 CSS 框架。与传统的语义化类名不同，Tailwind 通过组合工具类来构建界面。

## 响应式设计

Tailwind 的响应式设计非常直观，所有工具类都支持断点前缀：

```html
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3">
  <!-- 响应式网格 -->
</div>
```

## 暗色模式

Tailwind v4 原生支持 `dark:` 前缀，配合 `class` 策略可以轻松实现暗色切换：

```html
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
  自动适配暗色模式
</div>
```

## 组件化思维

将常用的样式组合提取为组件，可以避免类名过长的问题，同时保持 Tailwind 的灵活性。
